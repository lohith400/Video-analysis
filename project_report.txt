1. EXECUTIVE SUMMARY & SYSTEM PURPOSE
======================================
The Indian Road Intelligence System (IRIS) is an enterprise-grade, real-time traffic monitoring, automated safety enforcement, and computer vision analytics platform. Custom-designed for Indian traffic dynamics and infrastructure, IRIS leverages state-of-the-art deep neural networks, multi-object tracking algorithms, digital image processing, and a high-performance web dashboard.

Key Operational Capabilities:
1. Real-Time Multi-Class Vehicle Detection & Tracking: Tracks 7 primary vehicle classes (Cars, Motorcycles/Scooters, Buses, Trucks, Auto-Rickshaws, Bicycles, Vans) with persistent track IDs.
2. Automatic Number Plate Recognition (ANPR): Detects license plates in localized vehicle crops, applies contrast-limited adaptive histogram equalization (CLAHE), executes EasyOCR character extraction, corrects Indian state codes & alphanumeric confusion, and validates using standard Indian plate regex.
3. Two-Wheeler Safety Compliance (Helmet Checker): Monitors motorcycles and scooters, isolates rider vs. pillion positions based on horizontal spatial distribution, and checks helmet compliance to flag violations in real-time.
4. Pedestrian & Demographic Classification: Filters out vehicle passengers using Intersection over Union (IoU) overlap thresholds and classifies pedestrians (Adult Male, Adult Female, Child) using custom deep learning combined with a dynamic height-ratio heuristic.
5. Telemetry & Historical Intelligence Analytics: Periodically logs non-blocking time-series traffic stats, license plate reads, helmet violations, and demographic breakdowns to a local CSV database (`traffic_log.csv`) every second.

5. ALGORITHMIC MATHEMATICS & TECHNICAL PIPELINES
=================================================

A. Multi-Object Tracking & Line-Crossing Geometry (`tracker.py` & `traffic_counter.py`):
----------------------------------------------------------------------------------------
1. ByteTrack Object Tracking:
   - Command Execution: `model.track(frame, persist=True, tracker='models/custom_bytetrack.yaml', conf=0.40, iou=0.5, half=True)`
   - Minimum Track Age Filter: `MIN_TRACK_AGE = 30 frames` (~1 second at 30 FPS). Any detection lasting fewer than 30 frames is rejected to prevent transient false positives and track fragmentation.

2. Centroid Tracking & CCW Line Crossing Math:
   - Bottom-Center Trajectory Point: `(cx, y2) = ((x1 + x2) // 2, y2)`
   - Counting Line Coordinate Percentage: `COUNTING_LINE_PCT = (0.0, 0.65, 1.0, 0.65)` (Horizontal line across 65% frame height).
   - Counter-Clockwise (CCW) Orientation Formula:
     ```python
     _ccw(A, B, C) = (C[1] - A[1]) * (B[0] - A[0]) - (C[0] - A[0]) * (B[1] - A[1])
     ```
   - Segment Intersection Condition (Checking trajectory segment AB against line segment CD):
     ```python
     check_intersection(A, B, C, D) = ((_ccw(A, B, C) > 0) != (_ccw(A, B, D) > 0)) and \
                                      ((_ccw(C, D, A) > 0) != (_ccw(C, D, B) > 0))
     ```
3. Majority-Vote Class Assignment & Dynamic Correction:
   - Maintains a list of raw YOLO predictions over the lifetime of a vehicle's track.
   - Computes statistical mode (frequency count) to set assigned class.
   - If a vehicle's voted class updates after counting (e.g., from Car to Truck), the counter dynamically decrements the old class count and increments the new class count.

B. ANPR & EasyOCR Preprocessing Pipeline (`ocr_engine.py`):
------------------------------------------------------------
1. Localized Crop Eligibility:
   - Vehicle bounding box height must exceed `MIN_VEHICLE_HEIGHT_FOR_OCR = 100 pixels`. Wastes zero OCR cycles on far-away unreadable vehicles.
   - Plate detection runs at `PLATE_CONF_THRESHOLD = 0.25` and `IOU_THRESHOLD = 0.5`.

2. Multi-Frame Stabilization & Rolling Window NMS:
   - Buffers 3 consecutive vehicle crops per track ID.
   - Executes Non-Maximum Suppression (NMS) over bounding boxes across the 3 frames to select the highest-confidence localized plate region.

3. Advanced Image Processing Pipeline:
   - Rescaling: Upscales plate crops to a minimum height of 200 pixels using cubic interpolation (`cv2.INTER_CUBIC`).
   - Contrast Enhancement: Applies CLAHE (`clipLimit=3.0`, `tileGridSize=(8, 8)`).
   - Denoising: Applies Bilateral Filtering (`d=11, sigmaColor=17, sigmaSpace=17`) to smooth noise while preserving character edges.
   - Binarization: Applies Otsu Thresholding (`cv2.THRESH_BINARY + cv2.THRESH_OTSU`).
   - Inverted Pass Fallback: Performs secondary OCR pass on bitwise-inverted binary image (`cv2.bitwise_not`).

4. Indian License Plate Character Corrections & Regex Validation:
   - Alphanumeric Position Correction Rules:
     * Characters 0–1: Mandatory State Prefix (corrected via character-to-letter map `CONFUSED_TO_LETTER`).
     * Characters 2–3: District/RTO Code (corrected via digit map `CONFUSED_TO_DIGIT`).
     * Trailing 4 Characters: Unique Registration Number (forced digits).
   - Valid Indian State Code Filter: Validates against 41 recognized Indian State/Territory prefixes (`MH`, `CG`, `KA`, `TS`, `UP`, `DL`, `GJ`, `TN`, `HR`, `WB`, etc.). Automatically fixes OCR state misreads (e.g., `M4` -> `MH`, `CQ` -> `CG`, `K4` -> `KA`).
   - Strict Indian Plate Regex: `^[A-Z]{2}[0-9]{2}[A-Z]{1,2}[0-9]{4}$`.
   - 2-Vote Confirmation Filter: Accumulates OCR outputs into a 10-attempt rolling history. Requires at least 2 matching reads before confirming the plate to the database and UI, purging garbage reads.

C. Two-Wheeler Safety Compliance Mechanics (`helmet_checker.py`):
-----------------------------------------------------------------
1. Two-Wheeler Isolation: Crops vehicles classified as `motorcycle` or `scooter`.
2. Occupant Spatial Sorting:
   - Sorts detected heads/occupants horizontally by `x_center = (x1 + x2) / 2`.
   - Leftmost occupant = Rider; Second leftmost occupant = Pillion.
3. Violation Escalation: If `without_helmet`, `no_helmet`, or exposed `head` is detected, logs violation with timestamp, plate number, and bounding box coordinates, and triggers frontend visual warnings.

D. Pedestrian Demographics & Child Classification (`pedestrian_detector.py`):
------------------------------------------------------------------------------
1. Vehicle Occupant Overlap Filtering:
   - Computes IoU between COCO `person` boxes (Class 0) and vehicle bounding boxes.
   - If `IoU >= PEDESTRIAN_VEHICLE_IOU (0.3)`, target is identified as an occupant inside a vehicle and discarded.
2. Dynamic Height-Ratio Child Heuristic:
   - Dynamically calculates the rolling average height of adult pedestrians (`avg_adult_height`).
   - If pedestrian height `< CHILD_HEIGHT_RATIO (0.60) * avg_adult_height`, person is reclassified as `Child` regardless of raw model prediction.

E. CSV Telemetry & Historical Database (`csv_logger.py`):
--------------------------------------------------------
- Logging Frequency: 1.0 second intervals via background daemon thread.
- Target Database File: `backend/traffic_log.csv`
- Current Database Volume: 4,459 active log records (~439.24 KB of structured traffic data).
- Log Schema:
  `timestamp, total_vehicles, cars, trucks, buses, auto_rickshaws, motorcycles, scooters, bicycles, plates_detected, helmet_violations, violation_details, pedestrians_detected, males, females, children`
