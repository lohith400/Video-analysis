Now create this script — extract_frames.py:
pythonimport cv2
import os

VIDEO_PATH   = "videos/L1.mp4"      # your video
OUTPUT_DIR   = "dataset/images/all"
FRAME_SKIP   = 10   # save every 10th frame (avoids near-duplicate frames)
MAX_FRAMES   = 800  # target: 800 images is enough to start

cap    = cv2.VideoCapture(VIDEO_PATH)
total  = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
saved  = 0
idx    = 0

print(f"Video has {total} frames. Extracting every {FRAME_SKIP}th frame...")

while cap.isOpened() and saved < MAX_FRAMES:
    ret, frame = cap.read()
    if not ret:
        break

    if idx % FRAME_SKIP == 0:
        filename = os.path.join(OUTPUT_DIR, f"frame_{saved:04d}.jpg")
        cv2.imwrite(filename, frame)
        saved += 1
        if saved % 50 == 0:
            print(f"  Saved {saved} frames...")

    idx += 1

cap.release()
print(f"\nDone. Saved {saved} images to {OUTPUT_DIR}/")
Run it:
bashpython3 extract_frames.py
You now have 800 images ready to annotate.

Step 2 — Annotate on Roboflow (Free)
This is the most important step. You are teaching the model what a number plate looks like.
Setup
1. Go to roboflow.com
2. Create free account
3. Click "Create New Project"
4. Project name: indian-plate-detector
5. Project type: Object Detection
6. Click Create Project
Upload
1. Click "Upload Data"
2. Drag your entire dataset/images/all/ folder
3. Wait for upload (800 images takes ~5 minutes)
4. Click "Finish Uploading"
Annotate
1. Click "Annotate"
2. Open first image
3. Press "B" to select bounding box tool
4. Draw a tight box around every number plate visible
5. Label: license_plate
6. Press right arrow → next image
7. Repeat for all 800 images
Annotation Tips
✅ Draw the box TIGHT — just around the plate text area
✅ Include plates that are slightly blurry — model needs to see these
✅ Annotate even partial plates (cut off at edge)
✅ Skip frames where plate is completely invisible
✅ One class only: license_plate
❌ Do not draw box around the whole vehicle
❌ Do not include the number plate holder frame, just the white/yellow plate
Time estimate: 800 images at ~10 seconds each = about 2.5 hours. Do it in batches.
Export
1. Click "Generate" → Create New Version
2. Preprocessing:
   - Resize: 640x640 (required for YOLOv8)
   - Auto-orient: ON
3. Augmentation (add these — they make your model stronger):
   - Flip: Horizontal OFF (plates are direction-sensitive)
   - Brightness: -25% to +25%
   - Blur: up to 1.5px (simulates moving vehicles)
   - Noise: up to 1% (simulates CCTV grain)
4. Click Generate
5. Click Export → YOLOv8 PyTorch → Download zip

Step 4 — Train the Model
Create train_plate_model.py:
pythonfrom ultralytics import YOLO
import torch

# Verify GPU
print(f"CUDA available: {torch.cuda.is_available()}")
print(f"GPU: {torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'None'}")

# Load base model — starts from COCO pretrained weights
# This is called transfer learning — much faster than training from scratch
model = YOLO("yolov8n.pt")  # nano = fastest, good for plates

results = model.train(
    data    = "plate_dataset/data.yaml",
    epochs  = 50,           # 50 passes through your dataset
    imgsz   = 640,          # resize all images to 640x640
    batch   = 16,           # process 16 images at once
                            # reduce to 8 if you get "CUDA out of memory"
    name    = "indian_plate_v1",   # results saved here
    device  = 0,            # GPU 0 (your CUDA GPU)
    half    = True,         # FP16 for faster training
    patience= 15,           # stop early if no improvement for 15 epochs
    save    = True,         # save best model
    val     = True,         # validate after each epoch
    plots   = True,         # save training graphs
    verbose = True,
)

print("\n✅ Training complete!")
print(f"Best model saved at: {results.save_dir}/weights/best.pt")

If mAP is Below 0.75 — How to Fix It
Problem: Not enough training images
Fix:     Collect 200 more frames from different videos
         Re-annotate and retrain

Problem: Plates too small in training images
Fix:     In Roboflow augmentation, add "Zoom In" 
         to create close-up plate examples

Problem: Loss not going down after epoch 20
Fix:     Reduce learning rate
         Add to train(): lr0=0.001, lrf=0.01

Problem: CUDA out of memory
Fix:     Reduce batch size: batch=8 or batch=4
